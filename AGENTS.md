## Tooling

- Use Bun for package scripts and dependency management.
- Before completing code changes, run the relevant checks from this directory:
  `bun run typecheck`, `bun run lint`, and/or `bun run build`.

## Generated Content

- `src/generated/heralds.ts` is generated by `scripts/generate-heralds.mjs`.
  Do not edit it manually; run `bun run generate:heralds` after changing its
  source data or generator.
